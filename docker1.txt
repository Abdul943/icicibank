Shell Form & Excutable Form
============================
RUN CMD, ENTRYPOINT's can be defined in shell form or executable form

Shell Form
---------
RUN excutabel arg1 arg2
Internally the commands is executed as bash/sh

/bin/<shell> -c executable arg1 arg2

RUN mkdir -p /opt/test

/bin/bash -c mkdir -p /opt/test

RUN yum install git -y

/bin/bash -c yum install git -y   

CMD echo welcome
/bin/bash -c echo welcome
CMD java -jar app.jar             #bash is a main process
/bin/bash -c java -jar app.jar    #child process#java is a child


ENTRYPOINT echo welcome
/bin/bash -c java -jar app.jar
ENTRYPOINT java -jar app.jar
/bin/bash -c java -jar app.jar  

Executable Form


Syntax
======
RUN ["executable","arg1","arg2"]

Internally it will be excuted as
/bin/excutable arg1 arg2

RUN ["mkdir", "-p", "/opt/test"]
/bin/mkdir -p /opt/test
RUN ["yum", "install", "git", "-y"]
/bin/yum install git -y

CMD ["echo", "welcome"]
/bin/echo welcome
CMD ["java", "-jar", "app.jar"]
/bin/java -jar app.jar

ENTRYPOINT ["echo", "welcome"]
/bin/echo welcome
ENTRYPOINT ["java", "-jar", "app.jar"]                  
/bin/java -jar app.jar   #main process#java is a main process

Multi Stage Dockerfile
----------------------
With Multi Stage builds you can
use multiple FROM statements in a
socker file.Each From can use a diffrent bas image,
each of them begins stage of the build,
you can selectively copy artifacts(files/folder) from one stage to another stage
leaving everything you don't in the final image.


Using Dokcerfile
1)Clone the project
2)Build application package using maven
3)Create an image which has only tomcat and application code.

FROM centos
RUN yum install git
RUN git clone https://github.com/MithunTechnologiesDevOps/maven-web-application.git
RUN curl
RUN tar -xvzf tomcat.tar
WORKDIR maven-web-application
RUN mvn clean package
RUN cp target/maven-web-application.war usr/local/tomcat/webapps/maven-web-application.war
