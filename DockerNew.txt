Shell Form & Excutable Form
============================
RUN CMD, ENTRYPOINT's can be defined in shell form or executable form

Shell Form
---------
RUN excutabel arg1 arg2
Internally the commands is executed as bash/sh

/bin/<shell> -c executable arg1 arg2

RUN mkdir -p /opt/test

/bin/bash -c yum install git -y   

CMD echo welcome
/bin/bash -c echo welcome
CMD java -jar app.jar             #bash is a main process
/bin/bash -c java -jar app.jar    #child process#java is a child


ENTRYPOINT echo welcome
/bin/bash -c java -jar app.jar
ENTRYPOINT java -jar app.jar
/bin/bash -c java -jar app.jar
