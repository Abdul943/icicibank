3 Life Cycles
-------------


LC                               Goals
---                              -----
clean                            clean: It wll deletes the previous build files

site                             site: It will generates the documentation

default                          validate: It will validates the project dir structure and resources files
                                 compile: It will compiles the java source code and unit test cases
                                 test: It will run the junit test casesss
                                 package: It will create the packages build artifacts (jar/war and ear)
                                 install: It will store the build artifacts into local repo
                                 deploy: It will store the build artifact into remote repo.
