CIDR
we need to define network [IP range] while creating virtual private cloud.
we need define network range in the form CIDR
allocating ip address and its routing 

SubnetS
-------
we devide/break vpc [network] into multiple subnetworks.
we can create 'N' number of subnets
we can create resources like ec2 load balancer and storages etc within subnets

types of subnets.
public subnet
subnet which will have access to internet called as public subnet.
servers created in public subnet can access internet and we can also reach servers from internet.
subnet wchih will have route [connection]to internet gateway in routetable called as public subnets

private subnet
subnet whcih will not have access to internet called as private subnet
server created in private subnet cannot access internet and we also cannot reach servers from internet
subnet which not route connection to internet getway in routetable called as private subnet.

Merge Function
==============
Merge Function combines multiple maps into a single map.

we can use merge function to assign tags to an ec2 instance and vpc etc.

tags = merge ({"Name" : "MithunTechnologies"}, var.common_tags)

  instance_type     = var.instancetype_of_ec2server
  availability_zone = "us-east-1a"

}

how merge funtion work

Map_1
{ "Name" : "MithunTechnologies" }

Map_2

var.common_tags
{
    "Project"   = "DevOps"
    "Environment" = "Production"
}

merged_result

{
     "Name" : "MithunTechnologies"
      "Project"   = "DevOps"
    "Environment" = "Production"
}

This Final map is assigned to the tags argument of ec2 instance so that will apply all the 3 tags to EC2 instance.

Advantages
Customization,
we can add specific tags [Name] while still applying standard tags.
reusability,
we can define common tags once [var.common_tag] and reuse them across resources within a project

the merge function in terraform code combines a specific tags ["Name" : "MithunTechnologies"] and reusable set of [comman_tags] into a single
set of tags for an ec2 instance

Splat Experssion
================
Splat Experssion [*] is used to extract/get single/multiple values from a resource that returns a list or map.

Syntax
resource_type.rresource_name[*].attribute
this tells terraform to give a list of attribute value from all instances of a resource.

splat experstion can be used when we've create multiple instances of a resources using count or for_each meta argumets.
splat expersstion can be used when we want to extract same attribute from each instance.

Element Funtion
===============
Element function is used to select a single element from a list by specified index and it's particularly useful when we're looping over lists

element(list, index)

list
list of values/objects

index
index value always start from 0.
index value of an element that we want to retrieve from the list.

locals{
  availability_zones =["us-east-1a, "us-east-1b", "us-east-1c"]
}

output "availability_zones"
{
     valuee = element(local,availabilty_zone, 1)
}
output
us-east-1a

Element function can be used when we need to rotate values across multiple resources like assigning availability zones and subnets etc.

resource "aws_instance" "Default_Region" 
{
  count = 3  

  ami           = "ami-068c0051b15cdb816"
  instance_type = "t2.medium"
  availability_zone = element(["us-east-1a", "us-east-1b", "us-east-1c"], count.index)
}

This assigns each ec2 instance a diffrent availability zone in a round robin strategy.

resource "aws_subnet" "public_subnets" {
  count = length(var.public_subnets_Cidrs)

  vpc_id                  = aws_vpc.main.id
  cidr_block              = element(var.public_subnets_Cidrs, count.index)
  availability_zone       = data.aws_availability_zones.availability_zones[count.index]
  map_public_ip_on_launch = var.map_public_ip_on_launch

  tags = merge({ "Name" : "${var.Project}_${var.enviornment}_VPC_PublicSubnet-${count.index + 1}", "kubernetes.io/role/eld" : "1" }, var.common_tags)
}

  availability_zone = data.aws_availability_zones.availability_zones[count.index]
